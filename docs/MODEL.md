# Local inference profile

Qwen3-4B-Instruct-2507 Q4_K_M GGUF is downloaded separately before offline use. Its URL, Apache-2.0 declaration, exact 2,497,281,120-byte size and SHA-256 are in `data/model-manifest.json`. Imports require that profile; old saved weights are reverified once before loading unless a matching private-file size/mtime has a previous verified import. Weight bytes stay in private storage and are mapped/read by llama.cpp; inference has no socket or remote dependency.

The pinned llama.cpp commit is `2145525a4081d66ff1a87cf43ef809f95a85ac0c`, with its Android JNI example adapted in `llama-lib`. Greedy decoding (temperature 0) keeps source checks and answers reproducible under a fixed backend. UTF-16/UTF-8 conversion preserves supplementary characters in questions and outputs. CPU inference uses 2–4 threads, a 4096-token context and a 256-token batch. App prompts are token-counted against 1400 tokens, verification against 2400, with room reserved for the system/chat format and completion. Oversized evidence drops whole final source blocks; it is never silently cut into a misleading fragment. Generation allows up to 256 tokens and trims incomplete final sentences.

`PromptPolicy.java` is shared with desktop model diagnostics. It treats source blocks as untrusted data and escapes chat control-token spellings. Grounded generation uses a small JSON grammar with source IDs bound to claims; the app renders ordinary sentences and citations, not JSON. Source-check generation is constrained to exactly `SUPPORTED` or `UNSUPPORTED`. `AnswerReview.java` checks complete sentences, citation structure and numbers within the cited sources. A second local source-check prompt rejects everything except the exact `SUPPORTED` verdict. Grammar enforcement fixes output structure, not factual correctness. It can still be fooled or mistaken; accepted source answers are not certified facts.

Source failure or missing/incomplete evidence can fall back to clearly labeled learned knowledge if the switch is enabled. Knowledge answers have no source citations and can be wrong. Recognized live-information requests do not generate answers. Attempts share 90 seconds, with a 55-second source phase when fallback is permitted. Cancellation reaches both Kotlin flow and native decode batches. Real phone tests must verify cancellation, throughput, memory and thermal behavior.

The default pack is 4.54 GB; pack plus model is 7.04 GB before overhead. This is storage accounting, not a RAM measurement. See DEVICE-VALIDATION.md for the actual <=12 GB hardware gate.
